# 📝 Todo App

A simple and responsive **Todo App** built with **Next.js**, **TypeScript**, and **Chakra UI**.  
This project is designed to demonstrate modern frontend development practices with clean UI and strong typing.

---

## 🚀 Features
- Add, edit, and delete tasks
- Mark tasks as complete/incomplete
- Responsive design with Chakra UI
- Type safety with TypeScript
- Production-ready Next.js setup

---

## 🛠️ Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/Ola-Adeeko/tactic.git
cd tactic
```


### 2. Install Dependencies
```
npm install
```

### 3. Run in Development Mode
```
npm run dev
```

The app will be available at http://localhost:3000

Production Build

```Build the App
npm run build

npm run start

```
By default, the app will run at http://localhost:3000
